# Mini AI Agency

Interactive Three.js virtual office prototype featuring 18 AI employee roles and planned zones for workstations, meeting room, recreation, dining, prayer, restrooms, reception and coffee.

## Current state

- V7 prototype is available as a downloadable archive in the ChatGPT conversation.
- The repository has been initialized, but the existing `index.html` and asset files **have not yet been uploaded**.
- Photorealistic GLB character files are **not bundled** with V7. No completed integration or production deployment is claimed.
